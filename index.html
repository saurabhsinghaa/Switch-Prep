High-Level Design (HLD)

An 8-week live system design program with mock interviews — covering foundations, infrastructure, databases, scalability, and 18+ classic system design problems.

8-Week Program

WEEK 01
Foundations & Mental Models
  • HLD interview approach at top product-based companies
  • CAP theorem & consistency models (eventual, strong, linearizable)
  • SQL vs NoSQL — when and why
  • Back-of-envelope estimation (QPS, storage, bandwidth)
  • API design & data modelling
WEEK 02
Core Infrastructure Building Blocks
  • Networking, load balancers (L4 vs L7, consistent hashing)
  • CDN, DNS, reverse proxies
  • Caching strategies (write-through, write-back, cache-aside, TTL)
  • Redis deep dive — data structures, eviction, pub/sub
WEEK 03
Database Deep Dive
  • Sharding strategies (range, hash, directory-based)
  • Replication (leader-follower, multi-leader, leaderless)
  • Database indexing internals (B-Tree, LSM tree)
  • Design: Key-Value Store
WEEK 04
Scalability Patterns
  • Message queues & event-driven architecture (Kafka, SQS)
  • Async processing, fan-out patterns
  • Rate limiting at scale (token bucket, sliding window — distributed)
  • Design: Notification System / Newsfeed
WEEK 05
High-Traffic Systems
  • URL shortener (hashing, redirection, analytics)
  • Pastebin / code sharing platform
  • Search autocomplete (trie at scale, typeahead service)
  • Design: Twitter / Instagram Feed
WEEK 06
Data-Intensive Systems
  • Time series databases, OLAP vs OLTP
  • Data warehousing basics, Lambda architecture
  • Distributed counters and leaderboards
  • Design: YouTube / Netflix (video streaming at scale)
WEEK 07
Reliability & Real-World Engineering
  • Distributed transactions (2PC, Saga pattern)
  • Idempotency, exactly-once semantics
  • Circuit breaker, bulkhead, retry with backoff
  • Design: Payment System / UPI-like Gateway
WEEK 08
Mock Interviews + Company Prep
  • Google, Microsoft, Amazon, Confluent & 20+ company HLD question sheets
  • How interviewers evaluate: breadth vs depth trade-offs
  • 2–3 full mock HLD interviews 1:1 with detailed feedback
  • Common mistakes and how to avoid them
